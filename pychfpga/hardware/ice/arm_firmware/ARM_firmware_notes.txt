ARM firmrware releases

R11.3: original, with dfmux libs and firmware
R11.3a: removed dfmux libs and firmware. libicecore.so does not support MGK7BP16 backplane part number
R11.3b: Fix backplane part number recognition with new libicecore.so. Can't read clock source
R11.3c: new uimage (uimage.old1) that properly sets direction. Boot hangs.
R11.3d: new uimage (uimage.d) that sets pulldowns instead of pullups. Boot hangs.
R11.3f: New MLO with 2s delay
R11.3f2: Same, but built with new tool
R11.3f3: Added linux boot delay
R11.3g: fixed SD card read error in 1st bootloader
R11.3h: fix libiceboard fan tray readout
