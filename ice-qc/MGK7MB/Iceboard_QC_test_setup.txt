Starting the test:
==================
	- Turn on power bars
	- Power up computer. Log in as sharktooth, password: iceqcuser
	- Power up Agilent multimeter
	- Power supply:
		- Disconnect power supply from mini-backplane (can just disconnect red banana),
		- Turn ON power supply
		- Set power supply to 18V +-0.2V (The Iceboard damage threshold is 21V)
		- Set current limit to max (coarse current know fully clockwise)
		- Turn OFF power supply
		- Reconnect to mini-backplane
	- Make sure the outputs of the USB port are powered on
	- Launch Firefox to test network connectivity
	- To start tests:
		- Double-click "run_QC.sh" on the desktop, and click "run in terminal". Resize the window at will.
		- Select "2" to start IceBoard tests
		- Enter 4-digit serial number of board in the menu prompt.
		- Enter test number
